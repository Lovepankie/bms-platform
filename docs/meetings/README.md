# Meetings

Technical notes from working sessions, one folder per date: `YYYY-MM-DD/<topic>.md`.

These notes are technical only. Commercial discussion, pricing, and anything naming the
pilot tenant, its staff or its borrowers stay outside this repository (AGENTS.md, content
boundary). Decisions reached in a meeting are recorded as ADRs or chapter changes; the
meeting note links to them.

Files under `docs/meetings/` may be self-merged by the author through a short-lived branch
and pull request (PROCESS.md section 6).
