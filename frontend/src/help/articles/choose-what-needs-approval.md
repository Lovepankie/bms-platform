An administrator chooses which actions wait for an administrator first, and from what amount.

1. Open **Business set-up** from the menu, then **Approval rules**.
   ![Open Approval rules](choose-what-needs-approval-1.webp)
2. Tick **Ask an administrator first** on an action, and type the amount it starts from. An action marked **Always on** always waits; you can still set its amount, where 0 means every one.
   ![Type the amount it starts from](choose-what-needs-approval-2.webp)
3. Tap **Review and save**, read the change in plain words, type your password or code and tap **Yes, save this**.
   ![Review and save](choose-what-needs-approval-3.webp)

> While an action waits, nothing changes, and the administrators are told.
